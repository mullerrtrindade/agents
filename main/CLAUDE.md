# Orientações para Claude — DIAK

Leia `PROJECT_CONTEXT.md` e `AGENTS.md` antes de iniciar qualquer atividade no repositório. Use esses arquivos como fonte compartilhada das regras e do contexto do projeto.

Ao receber uma tarefa, identifique o objetivo, verifique os arquivos relevantes, proponha mudanças pequenas e esclareça o que foi realmente executado. Respeite decisões existentes; não considere ideias como funcionalidades concluídas.

Ao terminar, forneça um resumo curto das alterações, arquivos afetados, testes e pendências para facilitar a continuidade do trabalho por outros assistentes.
